00:00–00:45第一关 · 第一次动手45 分钟＋

你会学会

  • 找到 Codex 当前工作区和文件位置。
  • 用一句目标和一个结果条件开始任务。
  • 看 Codex 改了什么，再亲自打开结果。

按时间走

  1. 00:00–00:08打开专用训练目录，认出当前项目和文件。
  2. 00:08–00:18说清想做的页面和“什么样算完成”。
  3. 00:18–00:30让 Codex 建页面，学员查看新增文件。
  4. 00:30–00:38在浏览器打开页面，确认结果真实可见。
  5. 00:38–00:45要求一个小修改，重新打开并指出改动。

产物与过关

带走一个能打开的简单页面页面文件确实存在；学员能找到它、打开它，并说出改动发生在哪里。
00:45–01:45第二关 · 把任务说清楚60 分钟＋

你会学会

  • 把目标、背景、限制和通过条件说完整。
  • 把“大而全”切成一次能检查的小改动。
  • 先看计划和差异，不满意时及时纠正。

按时间走

  1. 00:45–00:58补齐一个模糊需求里的目标、背景和限制。
  2. 00:58–01:12把待办清单拆成小功能，并选一个先做。
  3. 01:12–01:25让 Codex 复述计划；学员修正范围和遗漏。
  4. 01:25–01:37实现“输入并新增一条任务”。
  5. 01:37–01:45查看改动，逐项对照开始时的通过条件。

产物与过关

一份小任务说明 + 新增任务功能功能符合任务说明；学员能说出给了 Codex 哪些背景、限制和检查方法。
01:45–03:15第三关 · 做成一个小应用90 分钟＋

你会学会

  • 先定最小可用范围，再逐步加功能。
  • 一次改一项，改完就运行和检查。
  • 从报错和实际行为找线索，再让 Codex 修复。

按时间走

  1. 01:45–02:00定下待办清单还要完成的功能和边界。
  2. 02:00–02:20加上标记完成和删除任务。
  3. 02:20–02:35让刷新后的列表保留状态。
  4. 02:35–02:50亲自试新增、完成、删除和刷新四种情况。
  5. 02:50–03:05在可恢复的练习样例里处理一次小问题。
  6. 03:05–03:15复跑关键操作，查看最终改动并复盘。

产物与过关

一个能用的待办清单网页新增、完成、删除、刷新保留都能展示；学员能说清一次问题如何被发现和修好。
03:15–04:00第四关 · 留下可复用规则45 分钟＋

你会学会

  • 用 AGENTS.md 留下当前项目每次都要遵守的规则。
  • 知道 Skill、MCP、Git 分别解决哪类问题。
  • 用 Git 状态和差异看清改动范围。

按时间走

  1. 03:15–03:25看一个短规则文件，挑出适合长期保留的要求。
  2. 03:25–03:40写三条项目规则，再做一项小修改验证。
  3. 03:40–03:48看一个 Skill 模板，认识如何保存重复流程。
  4. 03:48–03:55查看 Git 状态和差异，理解改动与保存点。
  5. 03:55–04:00用自己的话区分规则、Skill、MCP。

产物与过关

一份实际生效的 AGENTS.mdCodex 后续修改遵守其中规则。认识 Skill、MCP、Git；本关不要求部署 MCP 或掌握所有 Git 命令。
04:00–05:00第五关 · 带回自己的工作60 分钟＋

你会学会

  • 把熟悉的小任务变成清楚、可检查的结果。
  • 自己拆解任务，让 Codex 按步骤执行。
  • 亲自检查并解释方法怎样迁移到下一次工作。

按时间走

  1. 04:00–04:10选一个低风险小任务，不拷入机密文件。
  2. 04:10–04:22写目标、背景、限制和通过条件。
  3. 04:22–04:37学员主导 Codex 做出一个小版本。
  4. 04:37–04:50运行或检查，提供证据并修正偏差。
  5. 04:50–05:00说明结果、验证方法和下一次的做法。

产物与过关

一项迁移挑战成果 + 学员复盘结果真实存在，学员能解释检查步骤。挑战关由学员完成，教练只按需提示。
