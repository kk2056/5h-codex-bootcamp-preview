# 五小时课程地图

## 学完后，学员能做到什么

五小时结束时，学员应能独立处理一个范围清楚的小任务：找到合适的工作区，说清目标和限制，让 Codex 分步修改，查看改动并运行结果；遇到一个常见问题时知道如何继续追查；能把反复使用的项目规则留下来；能把这套方法迁移到一项熟悉的工作中。

学员会做出一个轻量待办清单网页：新增任务、标记完成、删除任务，并在刷新后保留状态。课程默认用 HTML、CSS、JavaScript 和浏览器完成，不要求先安装前端框架。第四关会让学员认识 AGENTS.md、Skill、MCP 和 Git 的用途；五小时内重点练项目规则和 Git 查看改动，MCP 只学会判断何时需要，不要求搭建服务。

## 正式开课前（不占五小时）

1. 安装并登录 Codex，完成需要的账号或环境设置。
2. 打开单独的 Bootcamp 训练目录，不直接在工作或私人主项目里练习。
3. 确认预览页和计时脚本能运行，并确认 Codex 只在训练目录内改文件。
4. 讲清计时规则：开始后计时，按暂停后冻结，可隔天继续；课前准备不扣课时。

只有学员点击“开始训练”后才启动五小时计时。

## 300 分钟逐段安排

| 时间 | 关卡 | 学员正在做什么 | 本段带走什么 |
|---|---|---|---|
| 00:00–00:45 | 01 第一次动手 | 熟悉工作区、让 Codex 创建并打开一个页面，再做一次小修改。 | 知道项目目录和文件在哪里，知道如何查看一个真实结果。 |
| 00:45–01:45 | 02 把任务说清楚 | 给 Codex 目标、背景、限制和通过条件，再把一个小功能做出来。 | 会把模糊请求写成范围明确、可以检查的任务。 |
| 01:45–03:15 | 03 做成一个小应用 | 完成待办清单的主要功能、运行、处理一次准备好的小问题并复查。 | 会分步开发、看改动、运行应用和顺着报错找下一步。 |
| 03:15–04:00 | 04 留下可复用规则 | 为项目写简短 AGENTS.md；认识 Skill、MCP、Git 分别能解决什么问题。 | 会让项目规则持续生效，知道重复流程和外部工具应放在哪里。 |
| 04:00–05:00 | 05 带回自己的工作 | 独立选一个小任务，拆解、执行、检查并讲清方法。 | 能把同一套工作循环迁移到熟悉的工作里。 |

## 第 01 关｜第一次动手（00:00–00:45，45 分钟）

**学员会学到**

- Codex 正在操作哪个项目，工作区和电脑上的其他文件有什么边界。
- 文件名、文件夹、改动和运行结果各指什么。
- 怎样给一个简单目标，以及怎样确认结果符合要求。

**时间怎么花**

- 00:00–00:08：打开训练目录，查看 Codex 当前所在项目和文件。
- 00:08–00:18：向 Codex 说明要做的页面和通过条件。
- 00:18–00:30：让 Codex 建立页面；学员自己查看新增文件和内容。
- 00:30–00:38：在浏览器打开页面，确认它确实显示出来。
- 00:38–00:45：提出一个小修改，重新打开页面，并指出改动位置。

**产物与过关条件**：一个能打开的初始页面；学员能指出文件位置，并展示修改前后的区别。

## 第 02 关｜把任务说清楚（00:45–01:45，60 分钟）

**学员会学到**

- 一个好任务需要说清目标、背景、限制和检查方式。
- 怎样把“帮我做个完整应用”切成一次只做一个的小任务。
- 怎样先让 Codex 解释计划、问清不确定点，再开始修改。
- 怎样读 Codex 提出的改动，并指出不符合要求的地方。

**时间怎么花**

- 00:45–00:58：拿一个模糊需求，补上目标、背景、限制和通过条件。
- 00:58–01:12：把待办清单拆成页面、增加任务、完成任务等小块。
- 01:12–01:25：先让 Codex 复述计划，学员修正范围和遗漏。
- 01:25–01:37：只实现“输入并新增一条任务”。
- 01:37–01:45：看文件差异，逐项对照刚才写的条件。

**产物与过关条件**：一份明确的小任务说明和新增任务功能；学员能说出自己给了哪些背景、限制和通过条件。

## 第 03 关｜做成一个小应用（01:45–03:15，90 分钟）

**学员会学到**

- 先定“能用”的最小范围，再逐步加功能。
- 一次只改一项，改完就运行和检查。
- 看 Codex 修改了哪些文件，确认它没有顺手改出不需要的东西。
- 从报错文字和实际行为入手，补充信息、缩小问题，再让 Codex 修复。

**时间怎么花**

- 01:45–02:00：确定待办清单的最小完成条件，列出剩余功能。
- 02:00–02:20：加入标记完成和删除任务。
- 02:20–02:35：加入刷新后保留状态，并说明这是为了什么。
- 02:35–02:50：手动试用新增、完成、删除、刷新四种情况。
- 02:50–03:05：在独立练习文件中处理一个预置小问题，不影响已经完成的页面。
- 03:05–03:15：检查修复、复跑关键操作，并做一次整体复盘。

**产物与过关条件**：一个可运行的待办清单网页；新增、完成、删除和刷新保留都能看到；学员能展示一次问题如何被发现和修好。

## 第 04 关｜留下可复用规则（03:15–04:00，45 分钟）

**学员会学到**

- AGENTS.md 用来保存每次在这个项目里都该遵守的规则。
- Skill 用来保存一套可以重复调用的做事流程。
- MCP 用来连接 Codex 以外的工具或资料；不是初学者必须安装的东西。
- Git 的状态和差异能帮助学员看清哪些内容被改过，并留下回退点。

**时间怎么花**

- 03:15–03:25：看一个短 AGENTS.md 例子，找出适合长期保留的规则。
- 03:25–03:40：给待办项目写三条规则，并让 Codex 做一项小修改验证规则生效。
- 03:40–03:48：看一份简单 Skill 模板，识别“重复流程”如何写成可重用说明。
- 03:48–03:55：查看 Git 状态和差异，理解改动范围与保存点。
- 03:55–04:00：用大白话说清 AGENTS.md、Skill、MCP 各自的作用。

**产物与过关条件**：一份确实影响 Codex 行为的项目规则；学员能为一个日常重复任务判断该留成规则、Skill，还是连接外部工具。此关不要求完整配置 MCP 或掌握 Git 命令。

## 第 05 关｜带回自己的工作（04:00–05:00，60 分钟）

**学员会学到**

- 把一个熟悉但小的工作需求写成可交付结果。
- 独立补充背景和限制，要求 Codex 先拆解再动手。
- 亲自运行或检查结果，遇到不对时把证据告诉 Codex。
- 复盘哪些方法值得重复，下一次从哪里开始。

**时间怎么花**

- 04:00–04:10：选一个低风险、范围小的工作任务；不要把机密文件拷入训练目录。
- 04:10–04:22：写目标、背景、限制、通过条件，自己决定是否拆分。
- 04:22–04:37：让 Codex 执行一个小版本，学员主导每一步。
- 04:37–04:50：运行或检查成果，发现偏差时补充证据并修正。
- 04:50–05:00：讲清完成结果、验证方法、遇到的问题和可迁移的方法。

**产物与过关条件**：一份真实任务成果或可演示样例，加一段学员自己的复盘。教练不替学员做这一关。

## 五小时后会留下什么

1. 一个能运行的待办清单网页。
2. 一份可复用的小任务说明模板。
3. 一个写过并验证过的 AGENTS.md。
4. 一个学员自己选题的迁移挑战成果和简短复盘。
5. 一张课程报告：已完成关卡、实际消耗时间、还需要练习的地方。

“掌握”指能独立处理这类基础小任务，不代表五小时学会所有 Codex 功能。

## 教练提示强度

- **引导**：一次只讲当下必需的一步，等学员操作后再继续。
- **提示**：学员先尝试；卡住时只给能推进的关键线索。
- **挑战**：学员先独立拆解和执行，教练等到请求后再给提示。

每关都要看实际产物或运行结果，并请学员解释自己检查了什么。需要用户亲自在 Codex 中操作的能力，不以教练代做代替。
