# 5H CODEX BOOTCAMP

**给 Codex 新手的五小时实战 Skill：分段学习，亲手做出第一个能运行的小应用。**

> 五小时是累计的实际练习时间，可以暂停、分几天完成；不是要求连续坐五小时，也不是五小时精通 Codex。

## 这个仓库是做什么的

这里放的是 5H CODEX BOOTCAMP 学习包：Coach Skill、课程路线、可暂停的本地计时器，以及可单独安装的 Plugin。

它是独立制作的学习工具，不是 OpenAI 官方课程或认证。

## 适合谁

- 刚开始用 Codex，不知道怎么把任务讲清楚；
- 想亲手做出一个小应用，不想只看教程；
- 希望学会检查 Codex 的改动，并把方法带回自己的工作。

## 五小时后，你会带走

1. 一个能新增、完成、删除任务的待办网页；
2. 一套把需求拆小、检查结果、修正问题的方法；
3. 一份自己写过并验证过的项目规则；
4. 一个用这套方法完成的工作小挑战。

| 关卡 | 时间 | 主要练习 |
|---|---:|---|
| 第一次动手 | 45 分钟 | 打开工作区，做出第一个页面并检查 |
| 把任务说清楚 | 60 分钟 | 拆小任务，新增功能并检查改动 |
| 做成小应用 | 90 分钟 | 完成待办网页、运行并修正一次问题 |
| 留下可复用规则 | 45 分钟 | 写一份项目规则，认识 Skill、MCP 和 Git |
| 带回自己的工作 | 60 分钟 | 独立完成一个熟悉的小任务并复盘 |

完整任务、时间安排和过关证据见 [五关课程地图](curriculum/levels.md)。

## 怎么开始

### 最快预览仓库里的 Skill

1. 登录获授权的 GitHub 账号，下载仓库根目录的 5h-codex-bootcamp-preview.zip 并解压。
2. 在 Codex 中打开解压后的 5H CODEX BOOTCAMP 文件夹。
3. 新建 Codex 对话，输入：

       $codex-coach 先介绍课程路线

4. 看完路线后，准备好了再说“开始训练”。教练这时才会启动计时。

这个解压目录是课程项目，不要在你已有的工作项目里直接开课。课程进度会保存在这个目录的 progress 文件中。
如果你已经安装了独立 Plugin，请改用一个单独的空训练文件夹，并按下方的 Plugin 指南操作，避免同一个对话里出现两个同名教练。

### 安装独立 Plugin

如果你想把教练装进 Codex，再在一个单独的空训练文件夹里学习，请按 [Plugin 安装与首次开课](docs/plugin-install.md) 操作。安装后要新建 Codex 对话，再调用 $codex-coach。

## 开始前准备

- 能正常使用的 Codex 桌面版或 CLI；
- Python 3.9 或更新版本；
- 一个专门用于学习的文件夹，不放工作机密或私人项目文件。

课前准备不占五小时。计时只累计开始到暂停之间的时间，学习进度保存在本机，不做云同步。

## 当前预览版的边界

- Windows PowerShell 和 Windows Codex 的实机测试尚未完成。
- 自动逐关验收还没做完；教练会检查文件和运行结果，但不是所有关卡都能由脚本自动判定。
- 没有云账号、云同步、排行榜或付费系统。
